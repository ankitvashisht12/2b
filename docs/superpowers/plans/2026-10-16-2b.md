# 2b Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `2b` CLI, dashboard, and skill, and a one-time importer that moves existing artifact folders into the store.

**Architecture:** Plain Markdown files with one-line frontmatter are the only state. Small TypeScript modules (store, rules, schedule, week, find, check, dashboard, importer) are called by one CLI entry file. Node runs the TypeScript directly with type stripping. Recurring tasks run through macOS `launchd`.

**Tech Stack:** Node 22 (`--experimental-strip-types`), `node:test`, no npm dependencies, vanilla HTML/JS for the dashboard, `launchd`, `osascript`.

**Spec:** `docs/specs/2026-10-16-2b-design.md`

## Global Constraints

- No npm dependencies. Node stdlib only.
- Node 22.14: run with `node --experimental-strip-types --no-warnings`. Use `import type` / inline `type` for type-only imports. No enums, no parameter properties.
- Store root: `$TWOB_HOME`, else `~/.config/2b/config.json` `home`, else `~/obsidian/2b`.
- Folder and new file names: lowercase letters, digits, hyphens, dots only.
- Task folder names start with `yyyy-mm-dd-`.
- Project status: `active | paused | on-hold | done | archived`. Task status: `todo | doing | blocked | done | dropped`. `paused`, `on-hold`, `blocked`, `dropped` need a reason.
- Area: `work | personal`. Link types: `depends-on | follow-up | related`.
- Log line format: `- yyyy-mm-dd HH:MM <event> | <detail>`.
- Frontmatter values are plain scalars or one-line JSON (valid YAML flow). Deliberate simplification: no YAML library.
- Schedule format: `daily HH:MM`, `weekdays HH:MM`, `mon,wed,fri HH:MM`, `hourly`. Recurring run timeout: 15 minutes.
- No command deletes files, except `2b import apply` (junk: `node_modules`, `__pycache__`, `*.map`, `.DS_Store`) and `2b schedule sync` (its own plists).
- Code style: descriptive names, no comment that restates code. Commits atomic, body says why, no `Co-Authored-By` trailer.
- Code blocks marked `file=<path>` are complete file contents.

## Review Focus

1. A partial task id that matches several tasks (`2b show review`) must fail and list the candidates. It must not pick the first one. → Task 2 test.
2. Titles and reasons with `:`, `"`, `#`, or `yes` must survive a write and a read. → Task 1 test.
3. `launchd` runs with an almost empty environment. The plist must carry the absolute node path, `PATH`, `HOME`, and `TWOB_HOME`. → Task 4 test.
4. Import on the case-insensitive macOS file system: `README.md` becomes `readme.md` and keeps its full text as the body. An existing `log.md` keeps its old lines. → Task 7 test.
5. Week edges: an event on Sunday 23:30 belongs to that week, and an event on Monday 00:05 belongs to the next. → Task 5 test.

```ts file=src/frontmatter.ts
export type Fields = Record<string, unknown>;

// ponytail: values are plain scalars or one-line JSON (valid YAML flow style), so no YAML library.
// A hand-written block-style YAML list fails to parse; `2b check` reports it.
const PLAIN_SCALAR = /^[A-Za-z0-9_.\/~][A-Za-z0-9_ .\/~+:,()'-]*$/;
const YAML_KEYWORD = /^(true|false|yes|no|on|off|null|~)$/i;
const FRONTMATTER = /^---\n(?:([\s\S]*?)\n)?---(?:\n|$)/;

function formatValue(value: unknown): string {
  if (value === null || value === undefined || value === '') return '';
  if (typeof value !== 'string') return ' ' + JSON.stringify(value);
  const isPlain = PLAIN_SCALAR.test(value)
    && !value.includes(': ')
    && !value.endsWith(':')
    && !value.endsWith(' ')
    && !YAML_KEYWORD.test(value);
  return ' ' + (isPlain ? value : JSON.stringify(value));
}

function parseValue(key: string, raw: string): unknown {
  if (raw === '') return null;
  if (!/^["[{]/.test(raw)) return raw;
  try {
    return JSON.parse(raw);
  } catch {
    throw new Error(`frontmatter field "${key}" is not one-line JSON: ${raw}`);
  }
}

export function parse(text: string): { fields: Fields; body: string } {
  const match = text.match(FRONTMATTER);
  if (!match) return { fields: {}, body: text };
  const fields: Fields = {};
  for (const line of (match[1] ?? '').split('\n')) {
    if (!line.trim()) continue;
    const separator = line.indexOf(':');
    if (separator < 1) throw new Error(`frontmatter line has no key: ${line}`);
    const key = line.slice(0, separator).trim();
    fields[key] = parseValue(key, line.slice(separator + 1).trim());
  }
  return { fields, body: text.slice(match[0].length) };
}

export function serialize(fields: Fields, body: string): string {
  const lines = Object.entries(fields).map(([key, value]) => `${key}:${formatValue(value)}`);
  return `---\n${lines.join('\n')}\n---\n${body}`;
}
```

```ts file=src/store.ts
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { spawnSync } from 'node:child_process';
import { parse, serialize, type Fields } from './frontmatter.ts';

export class UserError extends Error {}

export const AREAS = ['work', 'personal'];
export const PROJECT_STATUSES = ['active', 'paused', 'on-hold', 'done', 'archived'];
export const TASK_STATUSES = ['todo', 'doing', 'blocked', 'done', 'dropped'];
export const CLOSED_STATUSES = ['done', 'archived', 'dropped'];
export const REASON_REQUIRED = ['paused', 'on-hold', 'blocked', 'dropped'];
export const LINK_TYPES = ['depends-on', 'follow-up', 'related'];
export const DATE = /^\d{4}-\d{2}-\d{2}$/;
export const CLI_PATH = path.join(import.meta.dirname, 'cli.ts');
// ponytail: Node 22 needs the flag; drop it on Node 23.6+
export const NODE_COMMAND = [process.execPath, '--experimental-strip-types', '--no-warnings', CLI_PATH];

const SLUG = /^[a-z0-9](?:[a-z0-9.-]*[a-z0-9])?$/;
const DATE_PREFIX = /^\d{4}-\d{2}-\d{2}-/;
const RECURRING_FIELDS = ['every', 'run', 'agent', 'command'];
const SETTABLE_FIELDS = {
  project: ['title', 'area', 'started', 'deadline'],
  task: ['title', 'started', 'due', 'repo', 'branch', ...RECURRING_FIELDS],
};

export type Kind = 'project' | 'task';
export type Entry = { kind: Kind; id: string; project: string; dir: string; fields: Fields; body: string };
export type Artifact = { path: string; title: string; about: string; why: string; added: string };
export type Link = { to: string; type: string };

export function expandHome(filePath: string): string {
  return filePath === '~' || filePath.startsWith('~/') ? path.join(os.homedir(), filePath.slice(1)) : filePath;
}

export function storeRoot(): string {
  if (process.env.TWOB_HOME) return path.resolve(expandHome(process.env.TWOB_HOME));
  const configFile = path.join(os.homedir(), '.config', '2b', 'config.json');
  if (fs.existsSync(configFile)) {
    const configuredHome = JSON.parse(fs.readFileSync(configFile, 'utf8')).home;
    if (configuredHome) return path.resolve(expandHome(configuredHome));
  }
  return path.join(os.homedir(), 'obsidian', '2b');
}

export function initStore(root: string): void {
  for (const folder of ['projects', 'inbox', 'learnings']) fs.mkdirSync(path.join(root, folder), { recursive: true });
  const rulesFile = path.join(root, 'rules.md');
  if (!fs.existsSync(rulesFile)) fs.writeFileSync(rulesFile, '# Global rules\n\n');
  if (!fs.existsSync(path.join(root, '.git'))) spawnSync('git', ['init', '-q', root]);
}

const pad = (value: number) => String(value).padStart(2, '0');

export function localDate(date = new Date()): string {
  return `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())}`;
}

export function localDateTime(date = new Date()): string {
  return `${localDate(date)} ${pad(date.getHours())}:${pad(date.getMinutes())}`;
}

export function fileTimestamp(date = new Date()): string {
  return `${localDate(date)}-${pad(date.getHours())}${pad(date.getMinutes())}${pad(date.getSeconds())}`;
}

export function addDays(day: string, count: number): string {
  const [year, month, dayOfMonth] = day.split('-').map(Number);
  return new Date(Date.UTC(year, month - 1, dayOfMonth + count)).toISOString().slice(0, 10);
}

export function assertSlug(slug: string, what: string): void {
  if (!SLUG.test(slug)) throw new UserError(`${what} "${slug}" must use lowercase letters, digits, hyphens, and dots only`);
}

export function assertOneOf(value: string, allowed: string[], what: string): void {
  if (!allowed.includes(value)) throw new UserError(`${what} must be one of: ${allowed.join(', ')}`);
}

export function assertDay(value: string, what: string, allowUnknown = true): void {
  if (DATE.test(value) || (allowUnknown && (value === 'unknown' || value === ''))) return;
  throw new UserError(`${what} must be yyyy-mm-dd${allowUnknown ? ' or "unknown"' : ''}`);
}

export function slugify(text: string): string {
  return text.toLowerCase().replace(/[^a-z0-9.]+/g, '-').replace(/^[-.]+|[-.]+$/g, '') || 'untitled';
}

export function readEntry(kind: Kind, project: string, dir: string): Entry {
  const { fields, body } = parse(fs.readFileSync(path.join(dir, 'readme.md'), 'utf8'));
  const id = kind === 'project' ? project : `${project}/${path.basename(dir)}`;
  return { kind, id, project, dir, fields, body };
}

export function writeEntry(entry: Entry): void {
  fs.writeFileSync(path.join(entry.dir, 'readme.md'), serialize(entry.fields, entry.body));
}

function foldersWithReadme(dir: string): string[] {
  if (!fs.existsSync(dir)) return [];
  return fs.readdirSync(dir).sort().filter(name => fs.existsSync(path.join(dir, name, 'readme.md')));
}

export function listProjects(root: string): Entry[] {
  const projectsDir = path.join(root, 'projects');
  return foldersWithReadme(projectsDir).map(slug => readEntry('project', slug, path.join(projectsDir, slug)));
}

export function listTasks(root: string, project?: string): Entry[] {
  const projectSlugs = project ? [project] : foldersWithReadme(path.join(root, 'projects'));
  return projectSlugs.flatMap(slug => {
    const tasksDir = path.join(root, 'projects', slug, 'tasks');
    return foldersWithReadme(tasksDir).map(folder => readEntry('task', slug, path.join(tasksDir, folder)));
  });
}

export function listEntries(root: string): Entry[] {
  return [...listProjects(root), ...listTasks(root)];
}

export function resolve(root: string, ref: string): Entry {
  const project = listProjects(root).find(entry => entry.id === ref);
  if (project) return project;
  const tasks = listTasks(root);
  const exact = tasks.filter(task => task.id === ref || path.basename(task.dir) === ref);
  const matches = exact.length > 0 ? exact : tasks.filter(task => task.id.includes(ref));
  if (matches.length === 1) return matches[0];
  if (matches.length === 0) throw new UserError(`no project or task matches "${ref}"`);
  throw new UserError(`"${ref}" matches more than one task:\n${matches.map(task => `  ${task.id}`).join('\n')}`);
}

export function appendLog(dir: string, event: string, detail = '', at = localDateTime()): void {
  const logFile = path.join(dir, 'log.md');
  const current = fs.existsSync(logFile) ? fs.readFileSync(logFile, 'utf8') : '# Log\n\n';
  if (!fs.existsSync(logFile)) fs.writeFileSync(logFile, current);
  const separator = current.endsWith('\n') ? '' : '\n';
  const cleanDetail = detail.replace(/\s+/g, ' ').trim();
  fs.appendFileSync(logFile, `${separator}- ${at} ${event}${cleanDetail ? ` | ${cleanDetail}` : ''}\n`);
}

export type ProjectOptions = { area: string; title?: string; deadline?: string; started?: string };

export function createProject(root: string, slug: string, options: ProjectOptions): Entry {
  assertSlug(slug, 'project');
  assertOneOf(options.area, AREAS, 'area');
  if (options.deadline) assertDay(options.deadline, 'deadline');
  const dir = path.join(root, 'projects', slug);
  if (fs.existsSync(dir)) throw new UserError(`project "${slug}" already exists`);
  fs.mkdirSync(path.join(dir, 'tasks'), { recursive: true });
  const title = options.title ?? slug;
  const entry: Entry = {
    kind: 'project', id: slug, project: slug, dir, body: `\n# ${title}\n`,
    fields: {
      title, area: options.area, status: 'active', 'status-reason': null,
      started: options.started ?? localDate(), deadline: options.deadline ?? 'unknown',
      repos: [], prs: [], resources: [], links: [],
    },
  };
  writeEntry(entry);
  appendLog(dir, 'created', title);
  return entry;
}

export type TaskOptions = {
  title?: string; due?: string; repo?: string; branch?: string; started?: string; body?: string;
  every?: string; run?: string; agent?: string; command?: string;
};

export function createTask(root: string, project: string, slug: string, options: TaskOptions = {}): Entry {
  assertSlug(slug, 'task');
  const projectDir = path.join(root, 'projects', project);
  if (!fs.existsSync(path.join(projectDir, 'readme.md'))) throw new UserError(`project "${project}" does not exist`);
  if (options.due) assertDay(options.due, 'due');
  const started = options.started ?? localDate();
  const folder = DATE_PREFIX.test(slug) ? slug : `${started}-${slug}`;
  const dir = path.join(projectDir, 'tasks', folder);
  if (fs.existsSync(dir)) throw new UserError(`task "${project}/${folder}" already exists`);
  const title = options.title ?? slug;
  const isRecurring = Boolean(options.every);
  const fields: Fields = {
    title, kind: isRecurring ? 'recurring' : 'normal', status: isRecurring ? 'doing' : 'todo', 'status-reason': null,
    started, due: options.due ?? null, repo: options.repo ?? null, branch: options.branch ?? null,
    prs: [], resources: [], links: [], artifacts: [],
  };
  if (isRecurring) {
    const run = options.run ?? 'agent';
    assertOneOf(run, ['agent', 'command'], 'run');
    if (run === 'command' && !options.command) throw new UserError('a command task needs --command');
    if (run === 'agent' && !options.body) throw new UserError('an agent task needs --body with the rule the agent follows');
    const agent = options.agent ?? 'claude';
    assertOneOf(agent, ['claude', 'codex'], 'agent');
    Object.assign(fields, {
      every: options.every, run, agent: run === 'agent' ? agent : null, command: options.command ?? null,
      'last-run': null, 'last-result': null, 'last-log': null,
    });
  }
  fs.mkdirSync(dir, { recursive: true });
  const body = `\n# ${title}\n${options.body ? `\n${options.body}\n` : ''}`;
  const entry: Entry = { kind: 'task', id: `${project}/${folder}`, project, dir, fields, body };
  writeEntry(entry);
  appendLog(dir, 'created', title);
  return entry;
}

export function setStatus(entry: Entry, status: string, reason?: string): void {
  assertOneOf(status, entry.kind === 'project' ? PROJECT_STATUSES : TASK_STATUSES, `${entry.kind} status`);
  if (REASON_REQUIRED.includes(status) && !reason) throw new UserError(`status "${status}" needs --reason`);
  const previous = entry.fields.status;
  entry.fields.status = status;
  entry.fields['status-reason'] = reason ?? null;
  writeEntry(entry);
  appendLog(entry.dir, `status ${previous} -> ${status}`, reason ?? '');
}

export function setField(entry: Entry, field: string, value: string): void {
  assertOneOf(field, SETTABLE_FIELDS[entry.kind], `${entry.kind} field`);
  if (RECURRING_FIELDS.includes(field) && entry.fields.kind !== 'recurring') {
    throw new UserError(`"${field}" is only for recurring tasks`);
  }
  if (field === 'area') assertOneOf(value, AREAS, 'area');
  if (field === 'started') assertDay(value, 'started', false);
  if (field === 'deadline' || field === 'due') assertDay(value, field);
  if (field === 'run') assertOneOf(value, ['agent', 'command'], 'run');
  if (field === 'agent') assertOneOf(value, ['claude', 'codex'], 'agent');
  entry.fields[field] = value === '' ? null : value;
  writeEntry(entry);
  appendLog(entry.dir, `set ${field}`, value);
}

function pushUnique(entry: Entry, field: string, item: unknown, event: string, detail: string): void {
  const list = Array.isArray(entry.fields[field]) ? (entry.fields[field] as unknown[]) : [];
  if (list.some(existing => JSON.stringify(existing) === JSON.stringify(item))) return;
  entry.fields[field] = [...list, item];
  writeEntry(entry);
  appendLog(entry.dir, event, detail);
}

export function addPr(entry: Entry, url: string): void {
  pushUnique(entry, 'prs', url, 'pr', url);
}

export function addResource(entry: Entry, title: string, target: string): void {

  pushUnique(entry, 'resources', resource, 'resource', `${title} ${target}`);

export function addLink(root: string, entry: Entry, to: string, type: string): void {
  assertOneOf(type, LINK_TYPES, 'link type');
  const target = resolve(root, to);
  if (target.id === entry.id) throw new UserError('an entry cannot link to itself');
  pushUnique(entry, 'links', { to: target.id, type }, 'link', `${type} ${target.id}`);
}

export function reverseLinks(root: string, id: string): { from: string; type: string }[] {

    ((entry.fields.links as Link[] | null) ?? [])
      .filter(link => link.to === id)
      .map(link => ({ from: entry.id, type: link.type })));
}

export function addArtifact(entry: Entry, source: string, meta: { title?: string; about?: string; why?: string }): string {
  if (entry.kind !== 'task') throw new UserError('artifacts belong to a task; give a task id');
  const extension = path.extname(source).toLowerCase() || '.md';
  const baseName = path.basename(source, path.extname(source)).replace(DATE_PREFIX, '');
  const fileName = `${localDate()}-${slugify(baseName)}${extension}`;
  const target = path.join(entry.dir, fileName);
  if (fs.existsSync(target)) throw new UserError(`artifact "${fileName}" already exists in ${entry.id}`);
  if (fs.existsSync(source) && fs.statSync(source).isFile()) fs.copyFileSync(source, target);
  else fs.writeFileSync(target, '');
  const artifact: Artifact = { path: fileName, title: meta.title ?? baseName, about: meta.about ?? '', why: meta.why ?? '', added: localDate() };
  entry.fields.artifacts = [...((entry.fields.artifacts as Artifact[] | null) ?? []), artifact];
  writeEntry(entry);
  appendLog(entry.dir, `artifact ${fileName}`, artifact.about);
  return target;
}

export function createNote(root: string, folder: 'inbox' | 'learnings', slug: string, title?: string): string {
  assertSlug(slug, 'note');
  const today = localDate();
  const dir = folder === 'inbox' ? path.join(root, 'inbox') : path.join(root, 'learnings', today.slice(0, 7));
  fs.mkdirSync(dir, { recursive: true });
  const file = path.join(dir, `${today}-${slug}.md`);
  if (fs.existsSync(file)) throw new UserError(`${path.relative(root, file)} already exists`);
  const noteTitle = title ?? slug;
  fs.writeFileSync(file, serialize({ title: noteTitle, created: localDateTime() }, `\n# ${noteTitle}\n`));
  return file;
}
```

```ts file=src/rules.ts
import fs from 'node:fs';
import path from 'node:path';
import { UserError, type Entry } from './store.ts';

export type Level = 'global' | 'project' | 'task';
export type Rule = { level: Level; key: string | null; text: string };

const RULE_LINE = /^- (?:\[([a-z0-9-]+)\] )?(.+)$/;

export function assertRuleKey(key: string): void {
  if (!/^[a-z0-9-]+$/.test(key)) throw new UserError(`rule key "${key}" must use lowercase letters, digits, and hyphens`);
}

export function parseRules(text: string, level: Level): Rule[] {
  return text.split('\n').flatMap(line => {
    const match = line.match(RULE_LINE);
    return match ? [{ level, key: match[1] ?? null, text: match[2].trim() }] : [];
  });
}

export function mergeRules(globalRules: Rule[], projectRules: Rule[], taskRules: Rule[]): Rule[] {
  const seenKeys = new Set<string>();
  return [...taskRules, ...projectRules, ...globalRules].filter(rule => {
    if (!rule.key) return true;
    if (seenKeys.has(rule.key)) return false;
    seenKeys.add(rule.key);
    return true;
  });
}

export function rulesFile(root: string, entry: Entry | null): string {
  return entry ? path.join(entry.dir, 'rules.md') : path.join(root, 'rules.md');
}

function readRules(file: string, level: Level): Rule[] {
  return fs.existsSync(file) ? parseRules(fs.readFileSync(file, 'utf8'), level) : [];
}

export function rulesFor(root: string, entry: Entry | null): Rule[] {
  const globalRules = readRules(path.join(root, 'rules.md'), 'global');
  if (!entry) return globalRules;
  const projectRules = readRules(path.join(root, 'projects', entry.project, 'rules.md'), 'project');
  const taskRules = entry.kind === 'task' ? readRules(path.join(entry.dir, 'rules.md'), 'task') : [];
  return mergeRules(globalRules, projectRules, taskRules);
}

export function formatRules(rules: Rule[]): string {
  if (rules.length === 0) return 'No rules.';
  return [
    'If rules conflict, the more specific level wins (task > project > global).',
    ...rules.map(rule => `- (${rule.level}) ${rule.key ? `[${rule.key}] ` : ''}${rule.text}`),
  ].join('\n');
}

export function addRule(file: string, key: string | null, text: string): void {
  const lines = fs.existsSync(file) ? fs.readFileSync(file, 'utf8').split('\n') : ['# Rules', ''];
  const newLine = `- ${key ? `[${key}] ` : ''}${text.replace(/\s+/g, ' ').trim()}`;
  const existingIndex = key ? lines.findIndex(line => line.startsWith(`- [${key}] `)) : -1;
  if (existingIndex >= 0) {
    lines[existingIndex] = newLine;
  } else {
    while (lines.length > 0 && lines[lines.length - 1] === '') lines.pop();
    lines.push(newLine, '');
  }
  fs.writeFileSync(file, lines.join('\n'));
}

export function removeRule(file: string, keyOrText: string): boolean {
  if (!fs.existsSync(file)) return false;
  const lines = fs.readFileSync(file, 'utf8').split('\n');
  const index = lines.findIndex(line => line.startsWith(`- [${keyOrText}] `) || line === `- ${keyOrText}`);
  if (index < 0) return false;
  lines.splice(index, 1);
  fs.writeFileSync(file, lines.join('\n'));
  return true;
}
```

```ts file=src/schedule.ts
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { spawnSync } from 'node:child_process';
import {
  UserError, NODE_COMMAND, appendLog, fileTimestamp, listTasks, localDate, localDateTime, readEntry, writeEntry,
  type Entry,
} from './store.ts';
import { formatRules, rulesFor } from './rules.ts';

export type CalendarInterval = { Minute: number; Hour?: number; Weekday?: number };

const WEEKDAY_NUMBERS: Record<string, number> = { sun: 0, mon: 1, tue: 2, wed: 3, thu: 4, fri: 5, sat: 6 };
const WORKDAYS = ['mon', 'tue', 'wed', 'thu', 'fri'];
const DEFAULT_TIMEOUT_MS = 15 * 60 * 1000;

export function parseEvery(spec: string): CalendarInterval[] {
  const text = spec.trim().toLowerCase();
  if (text === 'hourly') return [{ Minute: 0 }];
  const match = text.match(/^([a-z,]+) (\d{1,2}):(\d{2})$/);
  if (!match) throw new UserError(`schedule "${spec}" must look like "daily 19:00", "weekdays 14:00", "mon,fri 10:00", or "hourly"`);
  const hour = Number(match[2]);
  const minute = Number(match[3]);
  if (hour > 23 || minute > 59) throw new UserError(`schedule "${spec}" has an invalid time`);
  if (match[1] === 'daily') return [{ Hour: hour, Minute: minute }];
  const days = match[1] === 'weekdays' ? WORKDAYS : match[1].split(',');
  return days.map(day => {
    if (!(day in WEEKDAY_NUMBERS)) throw new UserError(`unknown day "${day}" in schedule "${spec}"`);
    return { Weekday: WEEKDAY_NUMBERS[day], Hour: hour, Minute: minute };
  });
}

export function labelFor(taskId: string): string {
  return `com.2b.${taskId.replace(/\//g, '.')}`;
}

const xmlEscape = (text: string) => text.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');

export function plistFor(
  label: string, programArguments: string[], intervals: CalendarInterval[],
  environment: Record<string, string>, logFile: string,
): string {
  const argumentsXml = programArguments.map(argument => `    <string>${xmlEscape(argument)}</string>`).join('\n');
  const environmentXml = Object.entries(environment)
    .map(([key, value]) => `    <key>${xmlEscape(key)}</key><string>${xmlEscape(value)}</string>`).join('\n');
  const intervalsXml = intervals.map(interval => {
    const keys = Object.entries(interval).map(([key, value]) => `      <key>${key}</key><integer>${value}</integer>`).join('\n');
    return `    <dict>\n${keys}\n    </dict>`;
  }).join('\n');
  return `<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>${xmlEscape(label)}</string>
  <key>ProgramArguments</key>
  <array>
${argumentsXml}
  </array>
  <key>EnvironmentVariables</key>
  <dict>
${environmentXml}
  </dict>
  <key>StartCalendarInterval</key>
  <array>
${intervalsXml}
  </array>
  <key>StandardOutPath</key><string>${xmlEscape(logFile)}</string>
  <key>StandardErrorPath</key><string>${xmlEscape(logFile)}</string>
</dict>
</plist>
`;
}

function launchctl(action: 'bootstrap' | 'bootout', plistFile: string): void {
  spawnSync('launchctl', [action, `gui/${process.getuid?.() ?? 501}`, plistFile], { stdio: 'ignore' });
}

export function syncSchedules(
  root: string,
  { agentsDir = path.join(os.homedir(), 'Library', 'LaunchAgents'), load = true } = {},
): { written: string[]; removed: string[] } {
  const logsDir = path.join(os.homedir(), 'Library', 'Logs', '2b');
  fs.mkdirSync(agentsDir, { recursive: true });
  if (load) fs.mkdirSync(logsDir, { recursive: true });
  const wanted = new Map<string, string>();
  for (const task of listTasks(root)) {
    if (task.fields.kind !== 'recurring' || task.fields.status !== 'doing') continue;
    const label = labelFor(task.id);
    const environment = { PATH: process.env.PATH ?? '/usr/bin:/bin', HOME: os.homedir(), TWOB_HOME: root };
    const programArguments = [...NODE_COMMAND, 'run', task.id];
    wanted.set(label, plistFor(label, programArguments, parseEvery(String(task.fields.every)), environment, path.join(logsDir, `${label}.log`)));
  }
  const written: string[] = [];
  const removed: string[] = [];
  for (const fileName of fs.readdirSync(agentsDir)) {
    if (!fileName.startsWith('com.2b.') || !fileName.endsWith('.plist')) continue;
    const label = fileName.slice(0, -'.plist'.length);
    if (wanted.has(label)) continue;
    const plistFile = path.join(agentsDir, fileName);
    if (load) launchctl('bootout', plistFile);
    fs.rmSync(plistFile);
    removed.push(label);
  }
  for (const [label, plist] of wanted) {
    const plistFile = path.join(agentsDir, `${label}.plist`);
    if (fs.existsSync(plistFile) && fs.readFileSync(plistFile, 'utf8') === plist) continue;
    if (load && fs.existsSync(plistFile)) launchctl('bootout', plistFile);
    fs.writeFileSync(plistFile, plist);
    if (load) launchctl('bootstrap', plistFile);
    written.push(label);
  }
  return { written, removed };
}

export function agentArgv(agent: string, prompt: string, root: string): string[] {
  if (agent === 'codex') return ['codex', 'exec', '--skip-git-repo-check', '--sandbox', 'workspace-write', '-C', root, prompt];
  const home = os.homedir();
  return [
    'claude', '-p', prompt,
    '--allowedTools', 'Bash(2b:*)', 'Bash(sqlite3:*)', 'Read', 'Glob', 'Grep',
    '--add-dir', root, path.join(home, '.claude', 'projects'), path.join(home, '.codex', 'sessions'), path.join(home, '.t3', 'userdata'),
  ];
}

export function buildPrompt(root: string, task: Entry): string {
  const parts = [
    task.body.trim(),
    '',
    'Rules:',
    formatRules(rulesFor(root, task)),
    '',
    `You run as the recurring 2b task "${task.id}". Today is ${localDate()}. Use the 2b CLI for every change to the store.`,
  ];
  if (task.fields['last-result'] === 'error' && task.fields['last-log']) {
    const lastLog = path.join(task.dir, String(task.fields['last-log']));
    parts.push('', `The previous run failed. Read its log first and avoid the same failure: ${lastLog}`);
  }
  return parts.join('\n');
}

export function notify(title: string, message: string): void {
  if (process.env.TWOB_NO_NOTIFY) return;
  spawnSync('osascript', ['-e', `display notification ${JSON.stringify(message)} with title ${JSON.stringify(title)}`]);
}

export function runTask(root: string, task: Entry, { timeoutMs = DEFAULT_TIMEOUT_MS } = {}): { ok: boolean; logFile: string } {
  if (task.fields.kind !== 'recurring') throw new UserError(`${task.id} is not a recurring task`);
  const argv = task.fields.run === 'command'
    ? ['/bin/sh', '-c', String(task.fields.command ?? '')]
    : agentArgv(String(task.fields.agent ?? 'claude'), buildPrompt(root, task), root);
  const runsDir = path.join(task.dir, 'runs');
  fs.mkdirSync(runsDir, { recursive: true });
  const logFile = path.join(runsDir, `${fileTimestamp()}.log`);
  const result = spawnSync(argv[0], argv.slice(1), {
    cwd: root, encoding: 'utf8', timeout: timeoutMs, env: { ...process.env, TWOB_HOME: root },
  });
  const ok = result.status === 0 && !result.error;
  const failure = result.error ? `error: ${result.error.message}\n` : '';
  fs.writeFileSync(logFile, `$ ${argv.join(' ')}\n\n${result.stdout ?? ''}\n${result.stderr ?? ''}\n${failure}exit: ${result.status ?? result.signal}\n`);

  const fresh = readEntry('task', task.project, task.dir);
  fresh.fields['last-run'] = localDateTime();
  fresh.fields['last-result'] = ok ? 'ok' : 'error';
  fresh.fields['last-log'] = path.relative(task.dir, logFile);
  writeEntry(fresh);
  appendLog(task.dir, ok ? 'run ok' : 'run error', path.relative(task.dir, logFile));
  if (!ok) notify(`2b: ${fresh.fields.title} failed`, `See the dashboard or ${logFile}`);
  return { ok, logFile };
}
```

```ts file=src/week.ts
import fs from 'node:fs';
import path from 'node:path';
import { parse } from './frontmatter.ts';
import { listProjects, listTasks } from './store.ts';

export type LogEvent = { project: string; task: string | null; at: string; event: string; detail: string };

const LOG_LINE = /^- (\d{4}-\d{2}-\d{2} \d{2}:\d{2}) ([^|]+?)(?: \| (.*))?$/;

export function parseLog(text: string, project: string, task: string | null): LogEvent[] {
  return text.split('\n').flatMap(line => {
    const match = line.match(LOG_LINE);
    return match ? [{ project, task, at: match[1], event: match[2].trim(), detail: match[3] ?? '' }] : [];
  });
}

function readLog(dir: string): string {
  const logFile = path.join(dir, 'log.md');
  return fs.existsSync(logFile) ? fs.readFileSync(logFile, 'utf8') : '';
}

function noteEvents(root: string, folder: 'inbox' | 'learnings'): LogEvent[] {
  const dir = path.join(root, folder);
  if (!fs.existsSync(dir)) return [];
  return (fs.readdirSync(dir, { recursive: true }) as string[])
    .filter(file => file.endsWith('.md'))
    .flatMap(file => {
      try {
        const { fields } = parse(fs.readFileSync(path.join(dir, file), 'utf8'));
        if (typeof fields.created !== 'string') return [];
        return [{ project: folder, task: null, at: fields.created, event: folder === 'inbox' ? 'dump' : 'learning', detail: String(fields.title ?? file) }];
      } catch {
        return [];
      }
    });
}

export function readAllEvents(root: string): LogEvent[] {
  return [
    ...listProjects(root).flatMap(project => parseLog(readLog(project.dir), project.id, null)),
    ...listTasks(root).flatMap(task => parseLog(readLog(task.dir), task.project, task.id)),
    ...noteEvents(root, 'inbox'),
    ...noteEvents(root, 'learnings'),
  ].sort((first, second) => first.at.localeCompare(second.at));
}

export function isoWeek(day: string): { start: string; end: string } {
  const [year, month, dayOfMonth] = day.split('-').map(Number);
  const date = new Date(Date.UTC(year, month - 1, dayOfMonth));
  const daysSinceMonday = (date.getUTCDay() + 6) % 7;
  const start = new Date(Date.UTC(year, month - 1, dayOfMonth - daysSinceMonday));
  const end = new Date(Date.UTC(year, month - 1, dayOfMonth - daysSinceMonday + 6));
  return { start: start.toISOString().slice(0, 10), end: end.toISOString().slice(0, 10) };
}

export function weekEvents(root: string, day: string): LogEvent[] {
  const { start, end } = isoWeek(day);
  return readAllEvents(root).filter(event => {
    const eventDay = event.at.slice(0, 10);
    return eventDay >= start && eventDay <= end;
  });
}
```

```ts file=src/find.ts
import fs from 'node:fs';
import path from 'node:path';

export type FindHit = { file: string; line: number; text: string };

const TEXT_EXTENSIONS = new Set(['.md', '.html', '.json', '.jsonl', '.txt', '.csv', '.ts', '.tsx', '.js', '.mjs', '.py', '.yaml', '.yml', '.diff', '.log']);
const SKIPPED_FOLDERS = new Set(['.git', '.obsidian', 'node_modules', 'runs']);
const MAX_FILE_BYTES = 2_000_000;
const MAX_HITS_PER_FILE = 3;

export function findInStore(root: string, query: string, limit = 100): FindHit[] {
  const needle = query.toLowerCase();
  const hits: FindHit[] = [];
  const visit = (dir: string) => {
    for (const item of fs.readdirSync(dir, { withFileTypes: true })) {
      if (hits.length >= limit) return;
      const fullPath = path.join(dir, item.name);
      if (item.isDirectory()) {
        if (!SKIPPED_FOLDERS.has(item.name)) visit(fullPath);
        continue;
      }
      if (!item.isFile()) continue;
      const relativePath = path.relative(root, fullPath);
      if (relativePath.toLowerCase().includes(needle)) hits.push({ file: relativePath, line: 0, text: '(file name)' });
      if (!TEXT_EXTENSIONS.has(path.extname(item.name).toLowerCase()) || fs.statSync(fullPath).size > MAX_FILE_BYTES) continue;
      let hitsInFile = 0;
      fs.readFileSync(fullPath, 'utf8').split('\n').forEach((text, index) => {
        if (hitsInFile >= MAX_HITS_PER_FILE || hits.length >= limit || !text.toLowerCase().includes(needle)) return;
        hitsInFile += 1;
        hits.push({ file: relativePath, line: index + 1, text: text.trim().slice(0, 160) });
      });
    }
  };
  visit(root);
  return hits;
}
```

```ts file=src/check.ts
import fs from 'node:fs';
import path from 'node:path';
import {
  AREAS, DATE, PROJECT_STATUSES, REASON_REQUIRED, TASK_STATUSES, assertSlug, readEntry,
  type Entry, type Kind, type Link,
} from './store.ts';
import { parseEvery } from './schedule.ts';

function subfolders(dir: string): string[] {
  if (!fs.existsSync(dir)) return [];
  return fs.readdirSync(dir).filter(name => !name.startsWith('.') && fs.statSync(path.join(dir, name)).isDirectory()).sort();
}

function readOrReport(kind: Kind, project: string, dir: string, problems: string[]): Entry | null {
  const label = kind === 'project' ? project : `${project}/${path.basename(dir)}`;
  if (!fs.existsSync(path.join(dir, 'readme.md'))) {
    problems.push(`${label}: missing readme.md`);
    return null;
  }
  try {
    return readEntry(kind, project, dir);
  } catch (error) {
    problems.push(`${label}: ${(error as Error).message}`);
    return null;
  }
}

function checkEntry(entry: Entry, knownIds: Set<string>): string[] {
  const problems: string[] = [];
  const report = (message: string) => problems.push(`${entry.id}: ${message}`);
  const { fields } = entry;
  const folderName = path.basename(entry.dir);
  try {
    assertSlug(folderName, `${entry.kind} folder`);
  } catch (error) {
    report((error as Error).message);
  }
  if (entry.kind === 'task' && !/^\d{4}-\d{2}-\d{2}-/.test(folderName)) report('folder name must start with yyyy-mm-dd-');
  if (!fields.title) report('missing title');
  const statuses = entry.kind === 'project' ? PROJECT_STATUSES : TASK_STATUSES;
  const status = String(fields.status);
  if (!statuses.includes(status)) report(`status "${status}" is not one of ${statuses.join(', ')}`);
  if (REASON_REQUIRED.includes(status) && !fields['status-reason']) report(`status "${status}" needs status-reason`);
  if (entry.kind === 'project' && !AREAS.includes(String(fields.area))) report(`area "${fields.area}" is not one of ${AREAS.join(', ')}`);
  for (const dateField of ['deadline', 'due']) {
    const value = fields[dateField];
    if (value && value !== 'unknown' && !DATE.test(String(value))) report(`${dateField} "${value}" is not yyyy-mm-dd or unknown`);
  }
  for (const link of (fields.links as Link[] | null) ?? []) {
    if (!knownIds.has(link.to)) report(`link to "${link.to}" points to nothing`);
  }
  for (const artifact of (fields.artifacts as { path: string }[] | null) ?? []) {
    if (!fs.existsSync(path.join(entry.dir, artifact.path))) report(`artifact "${artifact.path}" is missing`);
  }
  if (fields.kind === 'recurring') {
    try {
      parseEvery(String(fields.every));
    } catch (error) {
      report((error as Error).message);
    }
  }
  return problems;
}

export function checkStore(root: string): string[] {
  const problems: string[] = [];
  const entries: Entry[] = [];
  const projectsDir = path.join(root, 'projects');
  for (const projectSlug of subfolders(projectsDir)) {
    const projectDir = path.join(projectsDir, projectSlug);
    const project = readOrReport('project', projectSlug, projectDir, problems);
    if (project) entries.push(project);
    for (const taskFolder of subfolders(path.join(projectDir, 'tasks'))) {
      const task = readOrReport('task', projectSlug, path.join(projectDir, 'tasks', taskFolder), problems);
      if (task) entries.push(task);
    }
  }
  const knownIds = new Set(entries.map(entry => entry.id));
  return [...problems, ...entries.flatMap(entry => checkEntry(entry, knownIds))];
}
```

```ts file=src/dash.ts
const CONTENT_TYPES: Record<string, string> = {
  '.html': 'text/html; charset=utf-8',
  '.json': 'application/json',

  '.jpg': 'image/jpeg',

export function entryDetail(root: string, id: string) {
  const entry = resolve(root, id);
  const logFile = path.join(entry.dir, 'log.md');
  return {
    id: entry.id,
    kind: entry.kind,
    fields: entry.fields,
    body: entry.body,

    log: fs.existsSync(logFile) ? fs.readFileSync(logFile, 'utf8') : '',
    tasks: entry.kind === 'project'
      ? listTasks(root, entry.id).map(task => ({ id: task.id, title: task.fields.title, status: task.fields.status }))
      : [],
  };

export function startDashboard(root: string, port: number): http.Server {
  const server = http.createServer((request, response) => {
    const url = new URL(request.url ?? '/', 'http://localhost');
    const sendJson = (data: unknown, status = 200) => {
      response.writeHead(status, { 'content-type': 'application/json' });
      response.end(JSON.stringify(data));
    };
    try {
      if (url.pathname === '/') {
        response.writeHead(200, { 'content-type': 'text/html; charset=utf-8' });
        response.end(fs.readFileSync(PAGE));
      } else if (url.pathname === '/api/ping') {
        sendJson({ ok: true, root });
      } else if (url.pathname === '/api/state') {
        sendJson(dashboardState(root, url.searchParams.get('week') || localDate()));
      } else if (url.pathname === '/api/entry') {
        sendJson(entryDetail(root, url.searchParams.get('id') ?? ''));
      } else if (url.pathname === '/api/file') {
        const filePath = path.resolve(root, url.searchParams.get('path') ?? '');
        const isInsideStore = filePath.startsWith(root + path.sep);
        if (!isInsideStore || !fs.existsSync(filePath) || !fs.statSync(filePath).isFile()) {
          sendJson({ error: 'not found' }, 404);
          return;
        }
        response.writeHead(200, { 'content-type': CONTENT_TYPES[path.extname(filePath).toLowerCase()] ?? 'text/plain; charset=utf-8' });
        response.end(fs.readFileSync(filePath));
      } else {
        sendJson({ error: 'not found' }, 404);
      }
    } catch (error) {
      sendJson({ error: (error as Error).message }, error instanceof UserError ? 404 : 500);
    }
  });
  server.listen(port, '127.0.0.1');
  return server;
}

export async function openDashboard(root: string, port: number): Promise<string> {
  const url = `http://127.0.0.1:${port}`;
  const isRunning = async () => {
    try {
      return (await fetch(`${url}/api/ping`)).ok;
    } catch {
      return false;
    }
  };
  if (!(await isRunning())) {
    spawn(NODE_COMMAND[0], [...NODE_COMMAND.slice(1), 'dash', '--port', String(port)], {
      detached: true, stdio: 'ignore', env: { ...process.env, TWOB_HOME: root },
    }).unref();
    for (let attempt = 0; attempt < 50 && !(await isRunning()); attempt += 1) {
      await new Promise(wait => setTimeout(wait, 100));
    }
  }
  spawnSync('open', [url]);
  return url;
}
```

```ts file=src/importer.ts
import fs from 'node:fs';
import path from 'node:path';
import {

const SKIPPED_NAMES = new Set(['CLAUDE.md', 'AGENTS.md', '.obsidian', '.DS_Store', '.git']);
const JUNK_FOLDERS = new Set(['node_modules', '__pycache__']);
const RECORD_FILES = new Set(['readme.md', 'log.md']);
const DATED_SLUG = /^\d{4}-\d{2}-\d{2}-/;

export type ScanItem = {
  source: string; group: string; type: 'dir' | 'file'; files: number; bytes: number;
  dateGuess: string; title: string | null; statusLine: string | null; topFiles: string[];
};
export type PlanProject = { slug: string; title: string; area: string; status: string; statusReason?: string; started?: string; description?: string };
export type PlanArtifact = { path: string; title?: string; about?: string; why?: string };
export type PlanItem = {
  source: string; project?: string; task?: string; inbox?: string; title?: string; status?: string; statusReason?: string;
  repo?: string; branch?: string; prs?: string[]; artifacts?: PlanArtifact[];
};
export type ImportPlan = { projects: PlanProject[]; items: PlanItem[] };
export type ImportReport = { moved: number; files: number; removedJunkBytes: number; problems: string[] };

const isJunkFile = (name: string) => name.endsWith('.map') || name === '.DS_Store';
const isDirectory = (target: string) => fs.statSync(target).isDirectory();

function keptFiles(target: string): string[] {
  if (!isDirectory(target)) return isJunkFile(path.basename(target)) ? [] : [target];
  return fs.readdirSync(target, { withFileTypes: true }).flatMap(item => {
    const fullPath = path.join(target, item.name);
    if (item.isDirectory()) return JUNK_FOLDERS.has(item.name) ? [] : keptFiles(fullPath);
    return item.isFile() && !isJunkFile(item.name) ? [fullPath] : [];
  });
}

function folderBytes(target: string): number {
  return fs.readdirSync(target, { withFileTypes: true }).reduce((total, item) => {
    const fullPath = path.join(target, item.name);
    if (item.isDirectory()) return total + folderBytes(fullPath);
    return total + (item.isFile() ? fs.statSync(fullPath).size : 0);
  }, 0);
}

function guessDate(name: string, text: string, files: string[]): string {
  const fromName = name.match(/(\d{4}-\d{2}-\d{2})/)?.[1] ?? name.match(/(20\d{2})(\d{2})(\d{2})/)?.slice(1).join('-');
  if (fromName) return fromName;
  const fromText = text.match(/started:?\s*(\d{4}-\d{2}-\d{2})/i)?.[1];
  if (fromText) return fromText;
  const earliest = files.reduce((oldest, file) => Math.min(oldest, fs.statSync(file).mtimeMs), Infinity);
  return localDate(Number.isFinite(earliest) ? new Date(earliest) : new Date());
}

function describe(target: string, group: string): ScanItem {
  const isDir = isDirectory(target);
  const files = keptFiles(target);
  const readmeName = isDir ? fs.readdirSync(target).find(name => name.toLowerCase() === 'readme.md') : undefined;
  const textFile = isDir ? (readmeName ? path.join(target, readmeName) : null) : (target.endsWith('.md') ? target : null);
  const text = textFile ? fs.readFileSync(textFile, 'utf8') : '';
  return {
    source: target,
    group,
    type: isDir ? 'dir' : 'file',
    files: files.length,
    bytes: files.reduce((total, file) => total + fs.statSync(file).size, 0),
    dateGuess: guessDate(path.basename(target), text, files),
    title: text.match(/^# (.+)$/m)?.[1].trim() ?? null,
    statusLine: text.match(/^status:.*$/im)?.[0].trim() ?? null,
    topFiles: isDir ? fs.readdirSync(target).filter(name => !SKIPPED_NAMES.has(name) && !JUNK_FOLDERS.has(name)).slice(0, 15) : [],
  };
}

export function scanSources(sources: string[]): ScanItem[] {
  return sources.map(expandHome).flatMap(sourceRoot => {
    if (!fs.existsSync(sourceRoot) || !isDirectory(sourceRoot)) throw new UserError(`${sourceRoot} is not a folder`);
    return fs.readdirSync(sourceRoot).sort()
      .filter(name => !SKIPPED_NAMES.has(name))
      .map(name => describe(path.join(sourceRoot, name), path.basename(sourceRoot)));
  });
}

function catchProblem(problems: string[], label: string, check: () => void): void {
  try {
    check();
  } catch (error) {
    problems.push(`${label}: ${(error as Error).message}`);
  }
}

function inboxTarget(root: string, item: PlanItem, source: string): string {
  return path.join(root, 'inbox', item.inbox + (isDirectory(source) ? '' : path.extname(source)));
}

export function validatePlan(root: string, plan: ImportPlan): string[] {
  const problems: string[] = [];
  const plannedProjects = new Set(plan.projects.map(project => project.slug));
  for (const project of plan.projects) {
    catchProblem(problems, project.slug, () => {
      assertSlug(project.slug, 'project');
      assertOneOf(project.area, AREAS, 'area');
      assertOneOf(project.status, PROJECT_STATUSES, 'project status');
    });
    if (REASON_REQUIRED.includes(project.status) && !project.statusReason) problems.push(`${project.slug}: status ${project.status} needs statusReason`);
  }
  const folderTargets = new Set<string>();
  for (const item of plan.items) {
    const source = expandHome(item.source);
    if (!fs.existsSync(source)) {
      problems.push(`${item.source}: source does not exist`);
      continue;
    }
    if (Boolean(item.inbox) === Boolean(item.task)) {
      problems.push(`${item.source}: give either project and task, or inbox`);
      continue;
    }
    if (item.inbox) {
      catchProblem(problems, item.source, () => assertSlug(item.inbox!, 'inbox name'));
      if (!DATED_SLUG.test(item.inbox)) problems.push(`${item.source}: inbox name must start with yyyy-mm-dd-`);
      if (fs.existsSync(inboxTarget(root, item, source))) problems.push(`${item.source}: inbox/${item.inbox} already exists`);
      continue;
    }
    const projectExists = item.project && (plannedProjects.has(item.project) || fs.existsSync(path.join(root, 'projects', item.project, 'readme.md')));
    if (!projectExists) problems.push(`${item.source}: project "${item.project}" is not in the plan or the store`);
    catchProblem(problems, item.source, () => assertSlug(item.task!, 'task'));
    if (!DATED_SLUG.test(item.task!)) problems.push(`${item.source}: task "${item.task}" must start with yyyy-mm-dd-`);
    if (item.status) {
      catchProblem(problems, item.source, () => assertOneOf(item.status!, TASK_STATUSES, 'task status'));
      if (REASON_REQUIRED.includes(item.status) && !item.statusReason) problems.push(`${item.source}: status ${item.status} needs statusReason`);
    }
    const target = path.join(root, 'projects', item.project ?? '', 'tasks', item.task!);
    if (fs.existsSync(target)) problems.push(`${item.source}: ${path.relative(root, target)} already exists`);
    if (isDirectory(source)) {
      if (folderTargets.has(target)) problems.push(`${item.source}: two folders target ${item.task}`);
      folderTargets.add(target);
    }
  }
  return problems;
}

function checksums(target: string): Map<string, string> {
  const base = isDirectory(target) ? target : path.dirname(target);
  return new Map(keptFiles(target).map(file => [
    path.relative(base, file),
    crypto.createHash('sha256').update(fs.readFileSync(file)).digest('hex'),
  ]));
}

function removeJunk(target: string): number {
  if (!isDirectory(target)) return 0;
  let removedBytes = 0;
  for (const item of fs.readdirSync(target, { withFileTypes: true })) {
    const fullPath = path.join(target, item.name);
    if (item.isDirectory() && JUNK_FOLDERS.has(item.name)) {
      removedBytes += folderBytes(fullPath);
      fs.rmSync(fullPath, { recursive: true, force: true });
    } else if (item.isDirectory()) {
      removedBytes += removeJunk(fullPath);
    } else if (item.isFile() && isJunkFile(item.name)) {
      removedBytes += fs.statSync(fullPath).size;
      fs.rmSync(fullPath);
    }
  }
  return removedBytes;
}

function move(source: string, destination: string): void {
  fs.mkdirSync(path.dirname(destination), { recursive: true });
  try {
    fs.renameSync(source, destination);
  } catch (error) {
    if ((error as NodeJS.ErrnoException).code !== 'EXDEV') throw error;
    fs.cpSync(source, destination, { recursive: true, preserveTimestamps: true });
    fs.rmSync(source, { recursive: true, force: true });
  }
}

function latestChange(dir: string): string {
  const latest = keptFiles(dir).reduce((newest, file) => Math.max(newest, fs.statSync(file).mtimeMs), 0);
  return localDateTime(latest ? new Date(latest) : new Date());
}

    fields: {
      title, kind: 'normal', status, 'status-reason': item.statusReason ?? null, started, due: null,
      repo: item.repo ?? null, branch: item.branch ?? null, prs: item.prs ?? [], resources: [], links: [], artifacts,
    },
  };
  writeEntry(entry);
  appendLog(taskDir, 'created', title, `${started} 00:00`);
  if (status !== 'todo') appendLog(taskDir, `status todo -> ${status}`, 'imported', latestChange(taskDir));
}

function registerLooseArtifact(item: PlanItem, taskDir: string, fileName: string): void {
  const entry = readEntry('task', item.project!, taskDir);
  const planned = item.artifacts?.find(artifact => artifact.path === fileName);
  const artifact: Artifact = {
    path: fileName, title: planned?.title ?? item.title ?? fileName, about: planned?.about ?? '', why: planned?.why ?? '', added: localDate(),
  };
  entry.fields.artifacts = [...((entry.fields.artifacts as Artifact[] | null) ?? []), artifact];
  writeEntry(entry);
  appendLog(taskDir, `artifact ${fileName}`, 'imported');
}

function verify(before: Map<string, string>, newPathFor: (relative: string) => string, label: string, originals: Map<string, string>): string[] {
  const problems: string[] = [];
  for (const [relative, hash] of before) {
    const newPath = newPathFor(relative);
    if (!fs.existsSync(newPath)) {
      problems.push(`${label}: ${relative} is missing after the move`);
      continue;
    }
    const original = originals.get(relative);
    if (original !== undefined) {
      const current = fs.readFileSync(newPath, 'utf8');
      const isReadme = /^readme\.md$/i.test(relative);
      const isPreserved = isReadme ? current.endsWith(original) : current.startsWith(original);
      if (!isPreserved) problems.push(`${label}: ${relative} lost its original text`);
      continue;
    }
    if (crypto.createHash('sha256').update(fs.readFileSync(newPath)).digest('hex') !== hash) problems.push(`${label}: ${relative} changed during the move`);
  }
  return problems;
}

export function applyPlan(root: string, plan: ImportPlan, { dryRun = false } = {}): ImportReport {
  const planProblems = validatePlan(root, plan);
  if (planProblems.length) throw new UserError(`plan has problems:\n${planProblems.map(problem => `  ${problem}`).join('\n')}`);
  const items = [...plan.items].sort((first, second) =>
    Number(!isDirectory(expandHome(first.source))) - Number(!isDirectory(expandHome(second.source))));
  const before = items.map(item => checksums(expandHome(item.source)));
  const files = before.reduce((total, map) => total + map.size, 0);
  if (dryRun) return { moved: items.length, files, removedJunkBytes: 0, problems: [] };

  for (const project of plan.projects) {
    if (fs.existsSync(path.join(root, 'projects', project.slug, 'readme.md'))) continue;
    const started = project.started ?? localDate();
    const entry = createProject(root, project.slug, { area: project.area, title: project.title, started });
    entry.fields.status = project.status;
    entry.fields['status-reason'] = project.statusReason ?? null;
    if (project.description) entry.body = `\n# ${project.title}\n\n${project.description}\n`;
    writeEntry(entry);
    fs.writeFileSync(path.join(entry.dir, 'log.md'), '# Log\n\n');
    appendLog(entry.dir, 'created', project.title, `${started} 00:00`);
  }

  let removedJunkBytes = 0;
  const problems: string[] = [];
  items.forEach((item, index) => {
    const source = expandHome(item.source);
    const sourceIsDir = isDirectory(source);
    removedJunkBytes += removeJunk(source);
    if (item.inbox) {
      const destination = inboxTarget(root, item, source);
      move(source, destination);
      const newPathFor = (relative: string) => sourceIsDir ? path.join(destination, relative) : destination;
      problems.push(...verify(before[index], newPathFor, item.source, new Map()));
      return;
    }
    const taskDir = path.join(root, 'projects', item.project!, 'tasks', item.task!);
    const originals = new Map<string, string>();
    if (sourceIsDir) {
      for (const name of fs.readdirSync(source)) {
        if (RECORD_FILES.has(name.toLowerCase())) originals.set(name, fs.readFileSync(path.join(source, name), 'utf8'));
      }
      move(source, taskDir);
      const readmeName = [...originals.keys()].find(name => name.toLowerCase() === 'readme.md');
      writeTaskRecord(item, taskDir, readmeName ? originals.get(readmeName)! : null);
      const newPathFor = (relative: string) => path.join(taskDir, /^readme\.md$/i.test(relative) ? 'readme.md' : relative);
      problems.push(...verify(before[index], newPathFor, item.source, originals));
    } else {
      const isNewTask = !fs.existsSync(taskDir);
      move(source, path.join(taskDir, path.basename(source)));
      if (isNewTask) writeTaskRecord(item, taskDir, null);
      else registerLooseArtifact(item, taskDir, path.basename(source));
      problems.push(...verify(before[index], relative => path.join(taskDir, relative), item.source, new Map()));
    }
  });
  return { moved: items.length, files, removedJunkBytes, problems };
}
```

```ts file=src/cli.ts
function formatWeek(start: string, end: string, events: LogEvent[]): string {
  if (events.length === 0) return `Week ${start} – ${end}: no activity recorded.`;
  const byProject = new Map<string, LogEvent[]>();
  for (const event of events) byProject.set(event.project, [...(byProject.get(event.project) ?? []), event]);
```

````markdown file=skill/SKILL.md
# 2b

All of the user's work state lives in the 2b store (`2b path` prints it; default `~/obsidian/2b`). Change it only through the `2b` CLI. Read files directly when you need their content. Never hand-edit `readme.md` frontmatter or `log.md`.

## Model

- **Project**: lasts weeks or months. Area `work` or `personal`. Status `active | paused | on-hold | done | archived`.
- **Task**: the atomic unit, about one PR or one investigation. Status `todo | doing | blocked | done | dropped`. Kind `normal` or `recurring`.
- **Artifact**: a file in a task folder, registered with `about` and `why`.
- **Log**: every CLI write appends a dated line. `2b week` reads these.
- `paused`, `on-hold`, `blocked`, `dropped` need `--reason`.
- Task ids accept any unique part of the name: `2b show limiter-recovery`.

## Requests and commands

| The user says | You run |
|---|---|
| "New project X" | `2b new project <slug> --area work --title "X"` |
| "Add a task to X" | `2b new task <project> <slug> --title "..." [--due yyyy-mm-dd]` |
| "Pause X because Y" | `2b status <project> paused --reason "Y"` |
| "Task T depends on U" | `2b add <T> link <U> depends-on` |
| "This PR is part of T" | `2b add <T> pr <url>` |
| "Save this / put it in 2b" | find or create the task, then `2b artifact add <task> <name.html> --about "..." --why "..."`, then write the content to the printed path |
| "What's active / paused / due?" | `2b ls --json`, `2b ls --status paused --json`, `2b ls --due-before +7d --json` |
| "What did I do this week / last week?" | `2b week [any day in that week] --json` |
| "Find the thing about Z" | `2b find "Z"` |
| "Quick note / dump" | `2b dump <slug> --title "..."`, then write to the printed path |
| "I learned X" | `2b learn <slug> --title "..."` |
| "Open the dashboard" | `2b dash --open` |

## Before you work on a task

1. `2b show <task>` — read status, links, artifacts, and recent log.
2. `2b rules <task>` — follow every rule. If rules conflict, the more specific level wins: task > project > global.
3. When you finish a step that matters, `2b log <task> "<one line>"`. When done, `2b status <task> done`.

## Rules

- "For this task never do X" → `2b rule add <task> --key <short-key> "Never do X."`
- "Globally, always do Y" → `2b rule add global --key <short-key> "Always do Y."`
- Use the same key as the rule you want to override at a less specific level.

## Recurring tasks

- "Every day at 7pm, do X" → `2b new task <project> <slug> --title "..." --every "daily 19:00" --run agent --body "<the full instruction>"`
- "On weekdays at 2pm open the dashboard" → `2b new task <project> <slug> --every "weekdays 14:00" --run command --command "2b dash --open"`
- Schedule format: `daily HH:MM`, `weekdays HH:MM`, `mon,fri HH:MM`, `hourly`.
- `2b schedule ls` shows last results. `2b run <task>` runs one now. A failed run sends a notification and shows on the dashboard; read its `last-log`, fix the cause, and run it again.

## Saving output

- Explainers and reports are HTML. Notes are Markdown.
- Always give `--about` (what it is) and `--why` (why it was made). Do not invent them; ask if you do not know.

## Answers

Short, plain terms. For "what did I do", group by project, one line per meaningful event, and skip noise such as `set` and `created` lines unless asked.

## Gotchas

- Put `--` before text that starts with a dash: `2b log <task> -- "--force was wrong"`.
- `2b check` reports broken links, missing reasons, and bad names. Run it after bulk changes.
````
