Scope: the public 2b website (landing page plus one page per version: v1, v2, v3). Mode: Persuade for the landing page, Read for the version pages.

Audience: developers on Apple silicon Macs who use Claude Code or Codex and want a local second brain. Job: understand what 2b is in seconds, then install it without guessing. Action: copy the quick-start commands; read the full steps; open GitHub. Proof: a working Today demo with sample data, real commands, real paths. Constraints: no private data, no invented claims or metrics, no license claim (the repo has none).

## Direction contract

THESIS: the page is a day book page from the product. One margin rule runs down the whole page; every section hangs on it. It refuses the split-hero-plus-feature-cards template.
OWN-WORLD: the v3 dashboard tokens (warm paper / ink night, terracotta margin rule at 45%, work blue, personal green), system sans, tabular numerals, lucide icons sitting on the rule.
STORY: the visitor sees their day in 2b, learns that items, links, and scope are the model, believes it is local and plain-file, and installs it in four commands.
FIRST VIEWPORT: wide headline top-left on the spine; quick-start command block with Copy directly under it; requirements line; on the right, the interactive Today demo at real dashboard scale.
FORM: user-pinned direction (match the v3 dashboard), code-led. seed: none (direction pinned by the user; no roll).
Signature interaction: the demo's scope switch and task checkboxes behave as in the product (rows fold in 180ms, strike fades in 200ms).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
